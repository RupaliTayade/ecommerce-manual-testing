# E-commerce Manual Testing Project

## Project Overview
This is a hands-on manual testing portfolio project
for an e-commerce demo application.

## Objectives
- Prepare and execute test cases.
- Perform positive and negative testing.
- Test product search and shopping cart workflows.
- Validate checkout form fields.
- Document defects and test results.

## Testing Types
- Functional Testing
- Smoke Testing
- Regression Testing
- Negative Testing
- UI and Usability Testing

## Tools
- GitHub
- Microsoft Excel / Google Sheets
- Web browser Developer Tools

## Project Status
In progress — test execution and results will
be documented as testing is performed.
