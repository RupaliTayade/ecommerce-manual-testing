
# OpenCart Manual Testing Project

## 1. Project Overview

This is a hands-on Manual QA Testing portfolio project
focused on testing the functionality of an e-commerce
web application.

The project demonstrates test planning, test case design,
manual test execution, defect reporting, and test summary
preparation.

## 2. Application Under Test

- **Application:** OpenCart Demo Store
- **Website URL:** https://demo.opencart.com/
- **Testing Type:** Manual Testing
- **Testing Approach:** Black-box Testing
- **Project Status:** In Progress

Note: This is an independent portfolio project and is
not an official engagement with OpenCart.

## 3. Project Objectives

- Validate core e-commerce functionalities.
- Prepare positive and negative test scenarios.
- Execute test cases and record actual results.
- Identify and document reproducible defects.
- Perform retesting and regression testing where possible.
- Prepare a test execution summary.

## 4. Scope of Testing

The planned testing areas include:

- Home Page and Navigation
- User Registration
- User Login and Logout
- Forgot Password
- Product Search
- Product Compare
- Product Details
- Add to Cart
- Wish List
- Shopping Cart
- Currency Selection
- Checkout
- My Account
- Order History
- Downloads
- Contact Us
- Category Pages
- Menu and Footer Options

Testing will depend on feature availability in the
public demo environment.
